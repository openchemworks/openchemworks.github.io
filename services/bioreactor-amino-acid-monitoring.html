Bioreactor Amino Acid Monitoring — A Standing Program, Not a One-Off Test

One bioreactor run, monitored whole: the full free amino acid profile (AA-1) on up to 24 time points, reported as one combined table and one trend chart across the run. $1,990 per run.

Request a QuoteExample report (PDF)

A run is a story. Single samples tell you frames.

One spent-media sample tells you what was left on the day it was pulled. It does not tell you when glutamine ran out, which amino acids depleted first, or whether the ammonia climb started before or after the feed change you are now debating. Those are run-level questions, and they are answered by a time course: the same panel, on samples pulled across the run, read together.

That is what this program is. RUN-1 packages one bioreactor run — up to 24 time points, the full free amino acid profile (AA-1) on each — and reports it as one combined table and one trend chart across the run, instead of 24 disconnected reports you have to stitch together yourself.

Who this is for

  • Fed-batch PD teams making feed decisions run to run: which amino acids are actually consumed, which are fed in excess, and where ammonia starts costing viability or titer.
  • Perfusion and intensified-process teams comparing runs, media lots or feed strategies on the same measured basis, rather than on end-of-run outcomes alone.
  • Fermentation and cultivated-meat teams tracking a complex nitrogen source — broth, hydrolysate, peptone — across a run, where the free fraction changes as the culture works.
  • Teams without in-house amino acid capacity. The search results for this work are dominated by instrument vendors selling analysers, kits and method development time. This page is the other option: ship the time points, get the run back as data. It is a laboratory service on shipped samples — not an in-line probe, not real-time monitoring, and the limits section below says so plainly.

If your job is a single question about a single sample, this program is not it — order the single-sample profile instead: Amino acid analysis, or start with Spent media analysis for one batch or time point.

What the program includes

The panel (AA-1, on every time point). 19 amino acids + ammonia per sample: alanine, arginine, asparagine, aspartate, glutamate, glutamine, glycine, histidine, isoleucine, leucine, lysine, methionine, phenylalanine, proline, serine, threonine, tryptophan, tyrosine, valine; and ammonia. Reported in µM and mg/L. This is the free amino acid profile — amino acids as they are in the medium or broth, not a hydrolysed total.

The method. AQC pre-column derivatization, reversed-phase HPLC on C18, UV detection at 260 nm; an internal standard (AABA) in every sample; a QC standard and reagent blanks in every run. The chemistry is described in How AQC Derivatization Works; how quality is controlled is on its own page.

The run report. One combined results table across all time points and a trend chart across the run — the form in which depletion curves and the ammonia curve can actually be read. Each underlying result carries the AA-1 report evidence (chromatogram, calibration and run QC summary). Reading support already on the site: Glutamine, Glutamate and Ammonia Across a Fed-Batch Run and Spent media analysis.

Settled before the run starts. An intake conversation fixes the time-point schedule, the fresh-medium baseline, free vs total (this program is free only — see the limits below), and whether the matrix is new to us (see the PREP-2 note under Prices). A run monitored on a schedule agreed in advance is a program; samples arriving at random are just samples.

The decisions a trend supports — and their limits

  • Feed: which amino acids deplete before the run ends, and which are still in excess at harvest — the two facts a feed reformulation actually turns on.
  • Harvest and run comparison: whether the ammonia curve and the depletion pattern of this run match the run you are trying to repeat, in the process record, with chromatograms behind the numbers.
  • Media and supplier changes: a new medium lot or nitrogen source read against the previous run's curve, not against memory.

Limits, stated as plainly: a trend shows what the culture consumed and produced. It does not by itself prove why a titer moved, and no causal claim about a feed change should be made from one run's curve alone.

What this program does not do. It is not real-time or in-line monitoring — samples are shipped to the lab and analysed in the weekly batch; if your control loop needs an answer inside the run's own shift, you need an in-house instrument, not this service. It measures free amino acids and ammonia only: it does not report total amino acid composition, protein content, or peptide content — those need hydrolysis (see total amino acid analysis). It does not detect creatine or other non-amino-acid ingredients; those need their own assays. The extended panel (AA-2), cysteine/cystine (AA-3) and taurine are not listed as part of this program and are not offered as part of it on this page.
